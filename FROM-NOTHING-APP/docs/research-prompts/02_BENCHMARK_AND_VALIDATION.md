# Prompt 02 — Shared Scientific Benchmark and Independent Validation
Implement an isolated experiment harness; reuse existing fixtures and canonical economics, never create a competing source of truth.
Build deterministic generators for 100/1k/5k/20k-task DAGs and optional 50-aircraft stress cases; configure precedence types/lags, resource capacities, named qualified crews, shift calendars, tool/zone exclusion, QA, material, rework, multimode labor, varying aircraft penalties and uncertainty. Scale according to actual runtime feasibility.
Benchmark same snapshots and seeds with baseline existing scheduler; paired comparisons at 1/10/60/300s; capture first-feasible latency, feasible rate, objective gap vs best known incumbent (not falsely called optimum), bound where valid, churn, memory, CPU, P95 latency, tail economic regret, and event-to-dispatch latency.
Use independent validation of all hard constraints including crew overlap, qualifications, precedence, temporal calendars, tooling, material, QA, zone and economic consistency. Inject deliberately invalid schedules to prove validator rejects them. Record synthetic provenance, scenario seeds, immutable baseline hashes, run versions, no real identifiers. Bootstrap confidence intervals; split training/selection/test scenarios and reserve unseen disruption families.
Deliver harness code, CLI, CI smoke suite, benchmark schema, baseline report and failure-injection tests. Never let a method pass solely on faster runtime with degraded validity.
GATE: baseline reproducible and independent validator passes before method experiments.
